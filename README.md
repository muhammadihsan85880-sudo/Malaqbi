# MALAQBI - Portal Pembelajaran Guru

Portal aplikasi berbasis web untuk guru dalam mengelola agenda harian, jurnal mengajar, presensi siswa, catatan guru, dan rekapitulasi penilaian kelas secara mandiri (offline-first).

## Fitur Utama
- **Agenda Harian**: Jadwal mengajar mingguan dan pelacakan kegiatan guru harian.
- **Presensi Kelas**: Pencatatan kehadiran siswa harian serta rekap absensi per periode.
- **Portal Penilaian**: Perhitungan nilai tugas, sumatif, SAS, dan penentuan predikat/KKM secara otomatis.
- **Catatan Guru**: Poin penghargaan dan catatan perkembangan karakter siswa.
- **Laporan & Cetak**: Fitur cetak rekap absensi dan nilai siswa.
- **Offline-First**: Seluruh data tersimpan di Local Storage peramban pengguna tanpa memerlukan database server eksternal.
